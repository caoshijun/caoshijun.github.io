rom_names.bin contains 16-pixel glyphs derived from GNU Unifont 16.0.04 by the GNU Unifont contributors, distributed under the SIL Open Font License 1.1. Glyphs are stored in Unicode order over the ranges declared in src/rom_title.cpp, with 32 bytes per glyph.
