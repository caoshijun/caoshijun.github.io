# CWBSM v3.1.2 手动烧录与测试

设备：ESP32，4 MB Flash。完整中日韩字体保留。

## 烧录

按开发板与屏幕选择 cyd_ili9341、cyd_st7789、e32r28t_ili9341 或 e32r28t_st7789 文件夹。不要混用：板型决定功放、RGB 灯和光敏电阻的引脚。

推荐保留配置的分地址烧录（在对应型号文件夹执行，替换 PORT）：

```sh
python -m esptool --chip esp32 --port PORT --baud 460800 --after hard-reset write_flash -z 0x1000 bootloader.bin 0x8000 partitions.bin 0xe000 boot_app0.bin 0x10000 firmware.bin
```

必须写入新的 partitions.bin：固件区 3.75 MiB，文件系统 128 KiB。NVS 配置区保留。无需 erase_flash。

若配置过静态 IP 后无法连接：长按 BOOT 5 秒松开进入配网；必要时通过后台恢复 DHCP。Wi-Fi 重置不清除其他设置。

## 测试清单

- 升级后原语言、天气城市、时区、模块、主题、MFA 和 Wi-Fi 是否保留。
- 系统二级菜单顺序：常规、显示、功能模块、当前屏幕、设备维护。
- 显示页面检查方向、主题、亮度、定时开关屏、状态栏、背灯；备份位于设备维护。
- 配网英文首屏，10 秒切换语言；触摸立即切换并重新计时；横竖屏都检查。
- 修改主机名并应用，检查 IP 访问与 hostname.local 访问（后者依赖本地 mDNS）。
- DHCP 切换固定 IP：正确地址可访问；非法地址、掩码、主机名应被拒绝；再切回 DHCP。
- 轮播与单屏总览互斥提示；轮播开启后应用分页项提示受全局控制，数据刷新仍生效。
- 动画：四向推出、四向擦除、中央展开、随机、无动画；100/400/2000 毫秒；左右触摸独立设置。
- 动画中连续触摸、打开菜单、转向、息屏后唤醒，不应死机或残影。
- GIF：开始、停止、下载；不重复启动；文件可播放；录到切页动画；断线显示错误并停止。
- GIF 固定参数：半分辨率 RGB332，目标 5 帧/秒，最多 20 秒或 100 帧；实际帧率受网络与设备负载影响。浏览器页面需保持打开。
- 动画中间画面使用半分辨率，完成后恢复清晰显示；MFA 页面不提供 GIF 采集。
- 中文生僻城市名、日文、韩文名称正常显示。
- 导出配置含主机名/IP/动画；恢复后设置一致；Wi-Fi 密码、MFA 密钥不进入配置备份。
- 观察设备维护内存，录屏与轮播运行 10 分钟检查响应；确认重启后配置保留。
